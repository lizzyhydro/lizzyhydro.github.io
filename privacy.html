개인정보처리방침

시행일: 2026년 11월 22일

1. 앱의 용도

"한줄살림상식 업로드" 앱은 채널 운영자 본인이 자신의 유튜브 채널에 영상을 올리고, 올린 영상의 제목·설명·썸네일을 수정하는 데에만 사용합니다. 운영자 외의 사용자에게 제공하지 않습니다.

2. 사용하는 정보

Google 계정 로그인으로 받은 권한(YouTube 업로드·관리)을 운영자 본인 채널에만 사용합니다. 다른 사람의 개인정보는 수집하지 않습니다.

3. 보관과 공유

로그인 정보는 운영자의 기기와 운영자가 관리하는 작업 환경에만 보관하며, 제3자에게 판매하거나 공유하지 않습니다.

4. Google API 데이터 사용

이 앱이 Google API로 받은 정보의 사용과 전송은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

5. 권한 철회

Google 계정의 "보안 → 서드 파티 앱 및 서비스"에서 언제든 이 앱의 접근 권한을 삭제할 수 있습니다.
